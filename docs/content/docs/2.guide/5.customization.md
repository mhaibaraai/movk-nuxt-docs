## 覆盖契约

在项目的组件目录（如 `app/components/`）中创建同名组件即可覆盖 Layer 的默认实现。组件名由文件名决定，`components/HeaderLogo.vue` 与 `components/header/HeaderLogo.vue` 都注册为 `HeaderLogo`。

下表是 v3 起承诺的可覆盖组件：组件名、挂载位置与 props 在 v3.x 内保持稳定。未列出的组件（如 `ThemePickerButton`）属于内部实现，可能随版本调整，不建议覆盖。

| 组件 | 挂载位置 | Props |
|------|----------|-------|
| `Header` | 每个页面顶部，路由 `meta.header` 为 `false` 时不渲染 | 无 |
| `HeaderLogo` | 头部左侧 | 无 |
| `HeaderCenter` | 头部中间（桌面端） | 无 |
| `HeaderCTA` | 头部右侧 | 无 |
| `HeaderBody` | 移动端导航抽屉 | 无 |
| `HeaderBottom` | 头部下方，仅文档页 | 无 |
| `LanguageSwitcher` | 头部右侧，启用国际化时 | 无 |
| `ThemePicker` | 头部右侧 | 无 |
| `PageHeaderLinks` | 文档页导语下方的元信息行 | 无 |
| `DocsAsideLeftTop` | 文档页左侧栏顶部 | 无 |
| `DocsAsideLeftBody` | 文档页左侧栏主体 | 无 |
| `DocsAsideRightBottom` | 文档页右侧目录下方 | 无 |
| `Footer` | 每个页面底部，路由 `meta.footer` 为 `false` 时不渲染 | 无 |
| `FooterLeft` | 页脚左侧 | 无 |
| `FooterRight` | 页脚右侧 | 无 |
| `ComponentExampleExtras` | `ComponentExample` 与 `ComponentCode` 的示例容器，需开启 `movkNuxtDocs.componentDocs` | 见 [ComponentExample](/docs/components/component-example#componentexampleextras) |

::tip
只想调整导航或文案时优先使用 `app.config`（如 `header.nav`、`footer.credits`），无需覆盖组件，见[配置](/docs/guide/configuration)。
::

## 头部 (Header)

页面顶部的完整导航系统，由多个子组件组成。

### `Header`

主容器组件，整合所有头部子组件，包括 Logo、导航菜单、搜索、主题选择器等功能。

可通过创建 `components/header/Header.vue` 完全自定义整个头部结构。

## 主题选择器 (ThemePicker)

### `ThemePicker`

主题自定义工具，提供可视化界面调整：

- **Primary**：主色调（支持设置为黑色或预设颜色）
- **Neutral**：中性色
- **Radius**：圆角大小（0-3）
- **Icons**：图标集选择
- **Color Mode**：颜色模式（亮色/暗色/系统）

修改后可导出 CSS 变量或 `app/app.config.ts` 配置。

[Agent Skills](https://agentskills.io) 是给 AI 助手的说明书：每个 Skill 是一个带 frontmatter 的 `SKILL.md`，描述助手能用你的产品完成什么任务、按什么步骤完成，并可以附带任意参考文件。

Movk Nuxt Docs 通过 [`nuxt-agent-discovery`](/docs/ai/agent-discovery) 在构建时扫描项目根目录的 `skills/`，生成索引并把文件发布到 `/.well-known/skills/` 下，遵循 [Agent Skills Discovery](https://github.com/cloudflare/agents/blob/main/docs/skills-discovery.md) 约定。

## 发布 Skill

::steps

### 创建目录

在项目根目录（与 `nuxt.config.ts` 同级）创建 `skills/`，每个 Skill 一个子目录：

```text
my-docs/
├── nuxt.config.ts
└── skills/
    └── my-skill/
        └── SKILL.md
```

### 编写 SKILL.md

`description` 必填，写清用途与触发场景，助手据此判断何时调用：

```md [skills/my-skill/SKILL.md]
---
name: my-skill
description: |
  为 My Library 编写组件文档。
  当用户要求「写组件文档」「补充 props 说明」时使用。
---

# My Skill

## 工作流程

1. 读取组件源码，列出 props、slots 与 emits
2. 按 references/template.md 生成页面
```

### 构建与部署

构建日志会列出发现的 Skill（`Found 1 agent skill: my-skill`），未通过校验的 Skill 会被跳过并输出警告。部署后可通过以下地址访问：

```bash [Terminal]
curl https://docs.example.com/.well-known/skills/index.json
curl https://docs.example.com/.well-known/skills/my-skill/SKILL.md
```

### 安装

读者用 [skills CLI](https://github.com/vercel-labs/skills) 安装站点发布的全部 Skill，CLI 会检测本机已安装的助手并逐一写入：

```bash [Terminal]
npx skills add https://docs.example.com
```

::

## 命名规则

Skill 名称取 frontmatter 的 `name`，省略时取目录名，必须满足：

- 1–64 个字符，仅包含小写字母、数字和连字符
- 不以连字符开头或结尾，不含连续连字符（`--`）
- 与所在目录名完全一致

## 目录结构

Skill 目录可以包含任意辅助文件，助手按需读取。以 `.` 开头的文件和目录、符号链接不会发布。

```text
skills/
└── my-skill/
    ├── SKILL.md
    ├── references/
    │   └── template.md
    └── assets/
        └── checklist.md
```

所有文件都会列在 `index.json` 中，并在 `/.well-known/skills/{name}/{path}` 下提供。`SKILL.md` 建议控制在 500 行以内，细节放进 `references/`，减少助手的上下文占用。

一个站点可以发布多个 Skill，索引按名称排序，助手根据 `description` 选择。

## 修改目录

扫描目录由 `agentDiscovery.skills.dir` 决定，相对项目根目录，layer 默认为 `skills`。设为 `false` 可关闭 Skill 发布：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  agentDiscovery: {
    skills: {
      dir: 'agent-skills'
    }
  }
})
```

## 内置 Skill

本站发布了两个 Skill，适用于任何使用 Movk Nuxt Docs 的项目：

| Skill | 用途 |
|-------|------|
| `create-docs` | 分析项目结构，生成基于 Movk Nuxt Docs 的完整文档站：目录、配置、页面与 AI 集成 |
| `review-docs` | 审查文档的结构、清晰度、SEO 与技术正确性，按 Critical / Important / Suggested 分级给出修改建议 |

```bash [Terminal]
npx skills add https://docs.mhaibaraai.cn
```

::note{to="https://docs.mhaibaraai.cn/.well-known/skills/index.json" target="_blank"}
查看本站发布的 Skill 索引
::

## 与 llms.txt 的区别

| | [llms.txt](/docs/ai/llms-txt) | Agent Skills |
|---|---|---|
| 内容 | 页面目录与链接 | 可执行的工作流、约束与示例 |
| 加载时机 | 助手查找资料时 | Skill 被触发时按需加载 |
| 作用 | 让助手找到信息 | 教助手如何使用你的产品 |

两者互补：`llms.txt` 告诉助手资料在哪里，Skill 告诉助手怎么做。

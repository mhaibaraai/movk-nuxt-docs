`useLocaleSeo()` 只在启用 `@nuxtjs/i18n` 且有效语言不少于 2 个时生效，否则直接返回，不注入任何标签。

## 用法

```vue [app/app.vue]
<script setup lang="ts">
await useDocsShell()
useLocaleSeo()
</script>
```

## 签名

```ts
function useLocaleSeo(): void
```

## 注入内容

| 标签 | 值 |
| --- | --- |
| `<link rel="alternate" hreflang="{code}">` | 每个有效语言一条，`href` 为 `site.url` 加该语言下的当前页路径 |
| `<link rel="alternate" hreflang="x-default">` | 指向语言列表中第一个语言的当前页 |
| `<meta property="og:locale">` | 当前语言代码，`-` 替换为 `_`，如 `zh_CN` |

## 注意事项

- 链接是绝对地址，需要在 `nuxt.config` 中配置 `site.url`。
- 目标语言下不存在的页面（`switchLocalePath` 返回空）不会生成对应的 alternate。

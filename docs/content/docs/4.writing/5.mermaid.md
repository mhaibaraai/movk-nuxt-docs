## 启用

Mermaid 默认关闭。

::steps{level="3"}
### 安装依赖

  ::code-group
  ```bash [pnpm]
  pnpm add mermaid dompurify
  ```

  ```bash [npm]
  npm install mermaid dompurify
  ```

  ```bash [yarn]
  yarn add mermaid dompurify
  ```

  ```bash [bun]
  bun add mermaid dompurify
  ```
  ::

### 开启功能开关

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@movk/nuxt-docs'],

  movkNuxtDocs: {
    mermaid: true
  }
})
```
::

::warning{to="/docs/guide/features"}
开启 `mermaid` 但未安装依赖时，构建会直接失败，并在错误信息中给出需要安装的包。未开启时，`mermaid` 代码块按普通代码展示。
::

## 用法

用语言为 `mermaid` 的代码块编写图表：

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```mermaid
flowchart LR
    A[编写 Markdown] --> B{包含 MDC 组件?}
    B -->|是| C[渲染 Vue 组件]
    B -->|否| D[渲染 Prose 元素]
    C --> E[输出页面]
    D --> E
```

#code
````md
```mermaid
flowchart LR
    A[编写 Markdown] --> B{包含 MDC 组件?}
    B -->|是| C[渲染 Vue 组件]
    B -->|否| D[渲染 Prose 元素]
    C --> E[输出页面]
    D --> E
```
````
::

- 跟随站点亮暗模式切换 Mermaid 主题
- 进入视口后才加载 `mermaid` 并渲染，不影响首屏
- 渲染结果经 DOMPurify 清理，Mermaid 以 `securityLevel: 'strict'` 运行
- 悬停时右上角显示复制源码与全屏查看按钮

### 文件名

与普通代码块一样，在方括号中写文件名，显示在图表顶部：

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```mermaid [ai-chat.mmd]
sequenceDiagram
    participant U as 读者
    participant P as 文档页
    participant A as AI Chat
    participant M as MCP Server
    U->>P: 提问
    P->>A: 发送消息
    A->>M: 调用文档工具
    M-->>A: 返回相关页面
    A-->>U: 流式输出回答
```

#code
````md
```mermaid [ai-chat.mmd]
sequenceDiagram
    ...
```
````
::

## 图表类型

### 类图

`classDiagram` 描述类型与继承关系：

```mermaid
classDiagram
    class Page {
        +String title
        +String description
        +String path
    }
    class DocsPage {
        +String category
        +Link[] links
    }
    class ReleasePage {
        +String tag
        +Date publishedAt
    }
    Page <|-- DocsPage
    Page <|-- ReleasePage
```

### 状态图

`stateDiagram-v2` 描述状态流转：

```mermaid
stateDiagram-v2
    [*] --> 草稿
    草稿 --> 审阅中: 提交 PR
    审阅中 --> 草稿: 需要修改
    审阅中 --> 已发布: 合并
    已发布 --> [*]
```

### 饼图

`pie` 展示占比：

```mermaid
pie title 示例：页面类型占比
    "指南" : 11
    "AI" : 5
    "写作" : 6
    "组件" : 7
    "参考" : 14
```

### 甘特图

`gantt` 展示计划与里程碑：

```mermaid
gantt
    title 示例：版本发布计划
    dateFormat YYYY-MM-DD
    section 开发
        功能实现    :a1, 2026-09-01, 21d
        文档重写    :a2, after a1, 14d
    section 发布
        Beta 测试   :b1, after a2, 7d
        正式发布    :milestone, after b1, 0d
```

### 实体关系图

`erDiagram` 描述数据实体及其关系：

```mermaid
erDiagram
    COLLECTION ||--o{ PAGE : contains
    COLLECTION {
        string name
        string locale
    }
    PAGE ||--o{ SECTION : has
    PAGE {
        string path PK
        string title
        string category
    }
    SECTION {
        string id PK
        string heading
    }
```

::tip{to="https://mermaid.js.org/intro/"}
更多图表类型与语法见 Mermaid 官方文档。
::

## 自定义样式

在 `app/app.config.ts` 的 `ui.prose.mermaid` 中覆盖各插槽的类名：

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      mermaid: {
        slots: {
          root: 'my-8 border-primary/40',
          diagram: 'bg-default p-6'
        }
      }
    }
  }
})
```

默认主题：

## 图片

### 远程图片

::code-preview
![Nuxt 社交图片](https://nuxt.com/new-social.jpg)

#code
```mdc
![Nuxt 社交图片](https://nuxt.com/new-social.jpg)
```
::

### 本地图片

本地图片放在站点的 `public/` 目录，以 `/` 开头引用：

::code-preview
![夕阳下云海中的雪山](/mountains.webp)

#code
```mdc
![夕阳下云海中的雪山](/mountains.webp)
```
::

::note{to="https://image.nuxt.com/"}
Markdown 图片由 `<NuxtImg>` 渲染，而不是原生的 `<img>`，可以使用 Nuxt Image 的优化能力。
::

方括号中的替代文本描述图片内容，供屏幕阅读器与搜索引擎读取。不要写「图片」「截图」这类没有信息量的词。

## 亮色与暗色截图

界面截图在亮色与暗色模式下差异明显时，用 `u-color-mode-image` 分别提供两张图，页面按当前主题显示对应的一张：

::code-preview
:u-color-mode-image{light="/assets/templates/movk-nuxt-light.png" dark="/assets/templates/movk-nuxt-dark.png" alt="@movk/nuxt 文档站首页" class="rounded-md border border-default"}

#code
```mdc
:u-color-mode-image{light="/assets/templates/movk-nuxt-light.png" dark="/assets/templates/movk-nuxt-dark.png" alt="@movk/nuxt 文档站首页" class="rounded-md border border-default"}
```
::

::tip
两张图保持相同尺寸，切换主题时页面不会跳动。
::

## 视频

`:video` 渲染原生 `<video>` 元素，属性与 HTML 一致：

::code-preview
:video{autoplay controls loop muted src="https://media.w3.org/2010/05/sintel/trailer.mp4"}

#code
```mdc
:video{autoplay controls loop muted src="https://media.w3.org/2010/05/sintel/trailer.mp4"}
```
::

浏览器只允许静音视频自动播放，使用 `autoplay` 时同时加上 `muted`。

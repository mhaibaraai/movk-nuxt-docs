除 [MDC 组件](/docs/writing/mdc-components) 中的 Nuxt UI Prose 组件外，layer 在 `components/content/` 中还提供下面两个可在 Markdown 中使用的组件。同目录下的 `HighlightInlineType`、`HeaderToggleButton` 供 Props 表格与页头内部使用，不建议在内容中直接引用。

## `Motion`

`Motion` 基于 [motion-v](https://motion.dev/docs/vue) 的 `Motion` 组件，为包裹的内容添加入场动画。默认效果是从模糊、略微放大的状态淡入：

::code-preview
  :::motion
  **Movk Nuxt Docs**：为 Nuxt 项目准备的编辑风文档主题。
  :::

#code
```mdc
::motion
**Movk Nuxt Docs**：为 Nuxt 项目准备的编辑风文档主题。
::
```
::

| Prop | 默认值 |
| --- | --- |
| `initial` | `{ scale: 1.1, opacity: 0, filter: 'blur(20px)' }`{lang="ts"} |
| `animate` | `{ scale: 1, opacity: 1, filter: 'blur(0px)' }`{lang="ts"} |
| `transition` | `{ duration: 0.6, delay: 0.1 }`{lang="ts"} |

其余 motion-v 的 `Motion` props 与 HTML 属性（如 `class`）原样透传。多个元素依次出现时，递增 `transition.delay`：

```mdc
::motion
**构建现代文档**
::

::motion
---
transition: { duration: 0.6, delay: 0.3 }
---
基于 Nuxt 4 的文档主题。
::

::motion{class="flex gap-3"}
---
transition: { duration: 0.6, delay: 0.5 }
---
  :::u-button{to="/docs/getting-started"}
  开始使用
  :::
::
```

## `StarsBg`

`StarsBg` 在所在区块后方绘制三层缓慢上升的星点，用于落地页的首屏或收尾区块。它以绝对定位铺在父元素范围内，父元素需要设置 `relative`，并通过 `isolate` 建立层叠上下文：

::code-preview
  :::div{class="relative isolate h-48 w-full overflow-hidden rounded-md border border-default"}
  :stars-bg
  :::

#code
```mdc
::div{class="relative isolate h-48 overflow-hidden"}
:stars-bg
::
```
::

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `starCount` | `number`{lang="ts-type"} | `300` | 三层星点的总数 |
| `color` | `string`{lang="ts-type"} | `'var(--ui-primary)'` | 星点颜色，接受任意 CSS 颜色 |
| `size` | `{ min: number, max: number }`{lang="ts-type"} | `{ min: 1, max: 2 }` | 星点尺寸范围，单位 px |

```mdc
:stars-bg{:star-count="120" color="var(--ui-text-muted)"}
```

::note
星点位置按页面路由缓存，服务端与客户端渲染结果一致。系统开启「减少动态效果」时，星点动画会停止。
::

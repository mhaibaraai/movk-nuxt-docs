## Override contract

Create a component of the same name in your project's components directory (e.g. `app/components/`) to override the layer's default implementation. The component name comes from the file name, so both `components/HeaderLogo.vue` and `components/header/HeaderLogo.vue` register as `HeaderLogo`.

The table below lists the overridable components guaranteed since v3: their names, mount points and props stay stable throughout v3.x. Components not listed (such as `ThemePickerButton`) are internal, may change between versions, and are not meant to be overridden.

| Component | Mount point | Props |
|-----------|-------------|-------|
| `Header` | Top of every page; not rendered when the route `meta.header` is `false` | None |
| `HeaderLogo` | Left side of the header | None |
| `HeaderCenter` | Center of the header (desktop) | None |
| `HeaderCTA` | Right side of the header | None |
| `HeaderBody` | Mobile navigation drawer | None |
| `HeaderBottom` | Below the header, docs pages only | None |
| `LanguageSwitcher` | Right side of the header, when i18n is enabled | None |
| `ThemePicker` | Right side of the header | None |
| `PageHeaderLinks` | Meta row below the docs page description | None |
| `DocsAsideLeftTop` | Top of the docs left sidebar | None |
| `DocsAsideLeftBody` | Body of the docs left sidebar | None |
| `DocsAsideRightBottom` | Below the docs right-hand table of contents | None |
| `Footer` | Bottom of every page; not rendered when the route `meta.footer` is `false` | None |
| `FooterLeft` | Left side of the footer | None |
| `FooterRight` | Right side of the footer | None |
| `ComponentExampleExtras` | Example container of `ComponentExample` and `ComponentCode`; requires `movkNuxtDocs.componentDocs` | See [ComponentExample](/en/docs/components/component-example#componentexampleextras) |

::tip
To change only navigation or text, prefer `app.config` (e.g. `header.nav`, `footer.credits`) over overriding components. See [Configuration](/en/docs/getting-started/configuration).
::

## Header

The complete navigation system at the top of the page, composed of multiple sub-components.

### `Header`

The main container component that brings together all header sub-components, including the logo, navigation menu, search, theme picker, and more.

You can fully customize the entire header structure by creating `components/header/Header.vue`.

## ThemePicker

### `ThemePicker`

A theme customization tool with a visual interface for adjusting:

- **Primary**: the primary color (can be set to black or a preset color)
- **Neutral**: the neutral color
- **Radius**: the border radius size (0-3)
- **Icons**: icon set selection
- **Color Mode**: color mode (light / dark / system)

After making changes, you can export the CSS variables or the `app/app.config.ts` configuration.

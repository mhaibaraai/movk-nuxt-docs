## What is Movk Nuxt Docs

Movk Nuxt Docs is a [Nuxt Layer](https://nuxt.com/docs/getting-started/layers) published as the npm package `@movk/nuxt-docs`. Add `extends: ['@movk/nuxt-docs']` to `nuxt.config.ts` and your project becomes a complete documentation site: header, sidebar, table of contents, full-text search, dark mode, SEO and OG images. All you write is Markdown in `content/docs/`.

It is built on [Nuxt 4](https://nuxt.com), [Nuxt UI](https://ui.nuxt.com) and [Nuxt Content](https://content.nuxt.com). Pages support [MDC syntax](/en/docs/writing/mdc-components), so you can use Vue components directly in Markdown.

## Included by default

Available right after installation, with no extra configuration:

- **Editorial typography**: serif headings, a numbered section bar, a warm paper background and a vermilion primary color; adjust it or switch back to sans-serif in [Theme and Fonts](/en/docs/guide/theme)
- **Navigation**: the sidebar is generated from the `content/docs/` directory; header links and sidebar categories are declared in `app.config.ts`, see [Navigation and Categories](/en/docs/guide/navigation)
- **Search**: ⌘K full-text search that shows recently visited pages of the current locale when empty
- **SEO**: sitemap, robots, Schema.org structured data and OG images generated at build time
- **MCP Server**: editors and AI assistants read the docs in a structured way through `/mcp`, see [MCP Server](/en/docs/ai/mcp)
- **AI-readable content**: `llms.txt`, a Markdown version of every page (`/raw/**.md`) and [agent discovery](/en/docs/ai/agent-discovery) endpoints
- **Git integration**: last commit time, edit links and [commit history components](/en/docs/components/commit-changelog)

## Opt-in features

These features are off by default. Their dependencies are optional peers that you install when you enable them; if a dependency is missing, the build fails with the install command. See [Feature Flags](/en/docs/guide/features).

| Feature | How to enable | Purpose |
|---------|---------------|---------|
| AI Chat | Set the `AI_API_KEY` environment variable, or `aiChat.enabled: true` | An AI assistant beside the docs, see [AI Chat](/en/docs/ai/ai-chat) |
| Component docs | `movkNuxtDocs.componentDocs: true` | Props, Slots and Emits tables and live examples generated from Vue source |
| Mermaid | `movkNuxtDocs.mermaid: true` | Flowcharts, sequence diagrams and more in code blocks, see [Mermaid](/en/docs/writing/mermaid) |
| Internationalization | Add `@nuxtjs/i18n` to `modules` | Multilingual content and a language switcher, see [Internationalization](/en/docs/guide/i18n) |
| Accessibility checks | `movkNuxtDocs.a11y: true` | Check pages with `@nuxt/a11y` during development |

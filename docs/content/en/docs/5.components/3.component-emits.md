`ComponentEmits` reads a component's `defineEmits` type and renders each event's name, parameter signature and description.

::note{to="/en/docs/components/component-props"}
Requires `movkNuxtDocs.componentDocs`, with the same prerequisites as [ComponentProps](/en/docs/components/component-props).
::

## Usage

::code-preview
:component-emits{slug="TestApi"}

#code
```mdc
:component-emits{slug="TestApi"}
```
::

Without `slug`, the component is resolved from the last segment of the current route.

## Documenting events

Declare events with the named tuple syntax and add JSDoc to each one. At build time the layer parses these comments from the source to fill in the event descriptions that `vue-component-meta` cannot read:

```vue [components/TestApi.vue]
<script setup lang="ts">
defineEmits<{
  /**
   * Emitted when the value changes
   * @see https://vuejs.org/guide/components/events.html
   */
  change: [value: string]
  /**
   * Emitted on delete
   */
  delete: []
}>()
</script>
```

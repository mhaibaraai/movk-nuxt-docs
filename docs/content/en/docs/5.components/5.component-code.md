`ComponentCode` needs no separate example file: give the component name and initial props in the frontmatter and you get an interactive preview with the matching Vue code.

::note{to="/en/docs/components/component-props"}
Requires `movkNuxtDocs.componentDocs`, with the same prerequisites as [ComponentProps](/en/docs/components/component-props).
::

## Usage

`name` is the PascalCase component name, either a Nuxt UI component or an auto-imported component from your project. Every key in `props` gets a control, and `items` provides the choices for a key:

:::code-preview
::component-code
---
name: UBadge
props:
  label: New
  color: primary
  variant: solid
items:
  color: [primary, secondary, success, warning, error, neutral]
  variant: [solid, outline, soft, subtle]
---
::

#code
```mdc
::component-code
---
name: UBadge
props:
  label: New
  color: primary
  variant: solid
items:
  color: [primary, secondary, success, warning, error, neutral]
  variant: [solid, outline, soft, subtle]
---
::
```
:::

Boolean props get `true` / `false` choices automatically, number props get a number input and everything else a text input. Boolean and string props equal to the component's default are left out of the snippet.

## Controlling the generated code

| Field | Effect |
| --- | --- |
| `ignore` | No control, but still written to the code; for fixed props |
| `hide` | Neither a control nor written to the code; for props that only affect the preview |
| `external` | Declared as a `ref` in `<script setup>` and bound by variable in the template |
| `model` | Bound with `v-model:{key}`; `modelValue` is always bound with `v-model` |
| `slots` | Slot content, keyed by slot name with template strings as values |

```mdc
::component-code
---
name: UInput
props:
  modelValue: ''
  placeholder: Search docs
  class: w-64
external: [modelValue]
hide: [class]
slots:
  trailing: <UKbd value="/" />
---
::
```

In the generated code above, `modelValue` becomes `const value = ref("")` bound with `v-model="value"`, while `class` only applies to the preview.

::tip{to="/en/docs/components/component-example#extending-the-example-container"}
ComponentCode and ComponentExample share the `ComponentExampleExtras` extension component.
::

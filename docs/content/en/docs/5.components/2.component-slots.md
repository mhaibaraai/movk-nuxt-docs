`ComponentSlots` reads a component's `defineSlots` type and renders each slot's name, scoped parameter type and description.

::note{to="/en/docs/components/component-props"}
Requires `movkNuxtDocs.componentDocs`, with the same prerequisites as [ComponentProps](/en/docs/components/component-props).
::

## Usage

::code-preview
:component-slots{slug="TestApi"}

#code
```mdc
:component-slots{slug="TestApi"}
```
::

Without `slug`, the component is resolved from the last segment of the current route.

## Documenting slots

Add JSDoc to every slot in `defineSlots`; the scoped parameter type is shown in the type column:

```vue [components/TestApi.vue]
<script setup lang="ts">
defineSlots<{
  /**
   * Default content slot
   */
  default(props?: {}): any
  /**
   * Avatar slot, exposes the avatar URL
   * @see https://ui.nuxt.com/components/avatar
   */
  avatar(props: { src: string }): any
}>()
</script>
```

`useDocsTheme()` drives the `ThemePicker` in the header. The theme configured in `app.config` is the baseline; visitor changes in the picker override it and persist to localStorage under keys prefixed with the site name (`site.name` in kebab-case).

## Usage

```vue
<script setup lang="ts">
const { primary, neutral, mode, resetTheme } = useDocsTheme()
</script>

<template>
  <UButton label="Blue" @click="primary = 'blue'" />
  <UButton label="Dark" @click="mode = 'dark'" />
  <UButton label="Reset" @click="resetTheme()" />
</template>
```

## Signature

```ts
function useDocsTheme(): {
  primary: WritableComputedRef<string | undefined>
  primaryColors: string[]
  neutral: WritableComputedRef<string | undefined>
  neutralColors: string[]
  radius: WritableComputedRef<number>
  radiuses: number[]
  icon: WritableComputedRef<string>
  icons: { label: string, icon: string, value: string }[]
  mode: WritableComputedRef<string>
  modes: ComputedRef<{ label: string, icon: string }[]>
  blackAsPrimary: ComputedRef<boolean>
  setBlackAsPrimary: (value: boolean) => void
  color: ComputedRef<string | undefined>
  style: { innerHTML: ComputedRef<string>, id: string, tagPriority: number }[]
  hasCSSChanges: ComputedRef<boolean>
  hasConfigChanges: ComputedRef<boolean>
  configLabel: string
  exportCSS: () => string
  exportConfig: () => string
  resetTheme: () => void
}
```

## Return Value

| Name | Type | Description |
| --- | --- | --- |
| `primary` | `WritableComputedRef<string \| undefined>` | Primary palette, applied through CSS variables; setting it turns off black as primary |
| `primaryColors` | `string[]` | Available primary colors: `vermilion` plus the chromatic Tailwind palettes |
| `neutral` | `WritableComputedRef<string \| undefined>` | Neutral palette, applied through CSS variables |
| `neutralColors` | `string[]` | Available neutrals: `paper`, `slate`, `gray`, `zinc`, `neutral`, `stone`, `taupe`, `mauve`, `mist`, `olive` |
| `radius` | `WritableComputedRef<number>` | Border radius in rem |
| `radiuses` | `number[]` | Available radii: `0`, `0.125`, `0.25`, `0.375`, `0.5` |
| `icon` | `WritableComputedRef<string>` | Icon set; writing it also replaces `appConfig.ui.icons` |
| `icons` | `{ label, icon, value }[]` | Available icon sets: `lucide`, `phosphor`, `tabler` |
| `mode` | `WritableComputedRef<string>` | Color mode, written to `colorMode.preference` |
| `modes` | `ComputedRef<{ label, icon }[]>` | `light`, `dark` and `system` |
| `blackAsPrimary` | `ComputedRef<boolean>` | Whether black (white in dark mode) is used as the primary color |
| `setBlackAsPrimary` | `(value: boolean) => void` | Toggle black as primary |
| `color` | `ComputedRef<string \| undefined>` | The neutral 50 / 950 shade for the current mode, used for `theme-color` |
| `style` | `object[]` | `<style>` tags for radius and black as primary, injected into head by the shell |
| `hasCSSChanges` | `ComputedRef<boolean>` | Whether palette, radius or black as primary differs from the baseline |
| `hasConfigChanges` | `ComputedRef<boolean>` | Whether the icon set differs from the baseline |
| `configLabel` | `string` | File name of the exported config, always `app.config.ts` |
| `exportCSS` | `() => string` | Export CSS variables that differ from the baseline |
| `exportConfig` | `() => string` | Export `defineAppConfig(...)` code for values that differ from the baseline |
| `resetTheme` | `() => void` | Clear visitor preferences and restore the `app.config` baseline |

## Baseline

The baseline palettes come from the CSS `@plugin "@nuxt/ui/colors"` configuration (`vermilion` / `paper` in the Layer). The remaining defaults are read from `app.config` on first call: `theme.radius` (default `0.25`), `theme.icons` (default `lucide`) and `theme.blackAsPrimary` (default `false`). To change the site's default theme, edit `app.config` rather than writing these refs in code, see [Theme and Fonts](/en/docs/guide/theme).

## External theme provider

The composable was renamed from `useTheme` to `useDocsTheme` to avoid collisions with component libraries. This page keeps its existing URL.

A consumer plugin named `docs-theme-provider` may provide a per-app `$docsTheme` object implementing `DocsTheme` (from `@movk/nuxt-docs/app/types/theme`). Register it before the Layer theme plugin, using `dependsOn` when another plugin restores preferences first. `useDocsTheme()` returns the supplied object, and the Layer skips its own storage restoration, CSS watchers and first-paint scripts. The header picker and `useDocsShell` use the supplied state, styles, defaults and reset behavior. An undefined primary or neutral selection means the stylesheet default applies. Without a provider, the built-in Layer theme remains active.

`useLocaleSeo()` only takes effect when `@nuxtjs/i18n` is enabled with at least two valid locales; otherwise it returns without injecting anything.

## Usage

```vue [app/app.vue]
<script setup lang="ts">
await useDocsShell()
useLocaleSeo()
</script>
```

## Signature

```ts
function useLocaleSeo(): void
```

## Injected Tags

| Tag | Value |
| --- | --- |
| `<link rel="alternate" hreflang="{code}">` | One per valid locale; `href` is `site.url` plus the current page's path in that locale |
| `<link rel="alternate" hreflang="x-default">` | Points to the current page in the first locale of the list |
| `<meta property="og:locale">` | Current locale code with `-` replaced by `_`, such as `zh_CN` |

## Notes

- Links are absolute, so `site.url` must be set in `nuxt.config`.
- No alternate is generated for a locale where the page does not exist (`switchLocalePath` returns an empty string).

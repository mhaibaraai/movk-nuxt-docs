This page lists every field available in `app/app.config.ts`. The tables are generated from `layer/nuxt.schema.ts`; run `pnpm docs:reference` after changing the schema.

`app.config` is read at runtime. Module-level switches (feature flags, AI models and so on) live in `nuxt.config.ts`, see [nuxt.config Options](/en/docs/reference/nuxt-config).

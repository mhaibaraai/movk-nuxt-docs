## How does it relate to the Nuxt UI docs template?

Movk Nuxt Docs grew out of the [Nuxt UI](https://ui.nuxt.com) docs site and the [UI docs template](https://docs-template.nuxt.dev/), and ships as a Nuxt Layer named `@movk/nuxt-docs`. On top of that it adds generated component docs, AI Chat, an MCP Server, Agent Skills, multiple languages and an editorial theme, and it regularly syncs upstream changes. You only add `extends: ['@movk/nuxt-docs']` to `nuxt.config.ts` instead of copying template code. See the [Introduction](/en/docs/getting-started).

## Do I have to use pnpm?

No. pnpm, npm, yarn and bun all work. The only hard requirement is Node.js 22.5 or later, because Nuxt Content relies on the built-in `node:sqlite`. With pnpm, allow the `sharp` build script in `pnpm-workspace.yaml`; see [Troubleshooting](/en/docs/guide/troubleshooting#image-processing-fails-after-a-pnpm-install).

## Can I skip `@nuxtjs/i18n` if I only need one language?

Yes, that is the default. Without `i18n` configured, the site runs in a single language with no locale prefix in URLs; switch the UI language with `i18n.locale` in `app.config`. See [Internationalization](/en/docs/guide/i18n#single-language-sites).

## Do docs have to live in `content/docs`?

Yes. Docs always live in `content/docs/` and are served under `/docs`; other locales go in `content/{code}/docs/`. The home page comes from `content/index.md`, or from your own page when `app/pages/index.vue` exists. See [Project Structure](/en/docs/getting-started/project-structure).

## How do I turn off the GitHub integration?

Set `github` to `false` in `app.config.ts`. Edit links, view source and commit history are all hidden:

```ts [app/app.config.ts]
export default defineAppConfig({
  github: false
})
```

When you keep it, the layer infers the repository from Git, and production needs `NUXT_GITHUB_TOKEN`. See [Configuration](/en/docs/guide/configuration).

## Can I use model providers other than OpenAI?

Yes. Set `AI_BASE_URL` to connect directly to any OpenAI-compatible endpoint (such as DeepSeek or Qwen); without it, `provider/model` model ids go through the Vercel AI Gateway. For a provider that is not OpenAI-compatible, register its AI SDK provider with `modelProviderRegistry.register()` in `server/plugins/`. See [AI Chat](/en/docs/ai/ai-chat).

## What if I do not want AI Chat?

Leave `AI_API_KEY` unset. AI Chat is off by default and its dependencies are not bundled. If `AI_API_KEY` exists in the build environment but you do not want AI Chat, set `aiChat.enabled: false`. See [Feature Flags](/en/docs/guide/features).

## How do I upgrade the layer?

Bump `@movk/nuxt-docs` and reinstall:

::code-group

```bash [pnpm]
pnpm add @movk/nuxt-docs@latest
```

```bash [npm]
npm install @movk/nuxt-docs@latest
```

```bash [yarn]
yarn add @movk/nuxt-docs@latest
```

```bash [bun]
bun add @movk/nuxt-docs@latest
```

::

When moving from v2 to v3, read the [Migration Guide](/en/docs/getting-started/migration) first; it lists every breaking change. Changes in each version are on the [Releases](/en/releases) page.

## How do I change the header, footer and other UI components?

Create a component with the same name in your project's `app/components/` to override the layer's implementation, for example `app/components/HeaderLogo.vue`. Only the components listed in the [override contract](/en/docs/guide/customization) keep their name, mount point and props stable across v3.x; the rest are internal. If you only need different navigation links, use `header.nav` in `app.config` instead; see [Navigation & Categories](/en/docs/guide/navigation).

## How do I change the primary color or fonts?

The default primary color is `vermilion`, the neutral is `paper` (a warm gray), and headings use a serif font. Change the primary color with `ui.colors` in `app.config`, and switch headings to sans-serif everywhere with `theme.font`. See [Theme & Fonts](/en/docs/guide/theme).

## Can I deploy it as a static site?

Yes. Run `nuxt generate` and deploy `.output/public/` to any static host. Pages, search, component docs and OG images all work, but AI Chat, the MCP Server, commit history and Markdown content negotiation need a server and are unavailable on a static site. See [Deployment](/en/docs/guide/deployment#static-generation).

## How do AI agents read my docs?

The layer provides `llms.txt`, an MCP Server and Markdown content negotiation out of the box: agents requesting a page can get Markdown directly, and `/raw/**.md` serves a Markdown version of every page. See [llms.txt](/en/docs/ai/llms-txt), [MCP Server](/en/docs/ai/mcp) and [Agent Discovery](/en/docs/ai/agent-discovery).

## What if builds are slow or run out of memory?

Turning off features you do not need cuts build work noticeably; for example `movkNuxtDocs.ogImage: false` skips rendering an OG image for every page. If Vercel runs out of memory, raise the Node.js heap limit; see [Troubleshooting](/en/docs/guide/troubleshooting#vercel-build-runs-out-of-memory).

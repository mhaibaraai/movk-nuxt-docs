## Build for production

```bash
pnpm build
```

The build output is located in the `.output/` directory and includes both server-side and client-side code.

## Vercel deployment

### Automatic deployment

1. Create a new project on Vercel
2. Connect your Git repository
3. Configure the environment variables:
   ```bash
   NUXT_GITHUB_TOKEN=your-token
   AI_API_KEY=your-key
   # AI_BASE_URL=https://api.example.com/v1
   ```
4. The deploy command defaults to `nuxt build`

## Environment variables

| Variable | Purpose | Required when |
|------|------|---------|
| `NUXT_GITHUB_TOKEN`{lang="ts-type"} | Git integration (commit history, last updated, releases) | Displaying commit history; the releases page works anonymously but is limited to 60 requests/hour |
| `AI_API_KEY`{lang="ts-type"} | AI Chat feature | Using AI Chat |
| `AI_BASE_URL`{lang="ts-type"} | Custom OpenAI-compatible endpoint; leave empty to use Vercel AI Gateway | Using AI Chat without AI Gateway |

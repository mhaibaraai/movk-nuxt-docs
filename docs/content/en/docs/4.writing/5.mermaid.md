## Enable

Mermaid is disabled by default.

::steps{level="3"}
### Install the dependencies

  ::code-group
  ```bash [pnpm]
  pnpm add mermaid dompurify
  ```

  ```bash [npm]
  npm install mermaid dompurify
  ```

  ```bash [yarn]
  yarn add mermaid dompurify
  ```

  ```bash [bun]
  bun add mermaid dompurify
  ```
  ::

### Turn on the feature flag

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@movk/nuxt-docs'],

  movkNuxtDocs: {
    mermaid: true
  }
})
```
::

::warning{to="/en/docs/guide/features"}
If `mermaid` is enabled without the dependencies installed, the build fails and the error lists the packages to install. When it is disabled, `mermaid` blocks are shown as plain code.
::

## Usage

Write a diagram in a code block with the `mermaid` language:

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```mermaid
flowchart LR
    A[Write Markdown] --> B{Has MDC components?}
    B -->|Yes| C[Render Vue components]
    B -->|No| D[Render prose elements]
    C --> E[Output page]
    D --> E
```

#code
````md
```mermaid
flowchart LR
    A[Write Markdown] --> B{Has MDC components?}
    B -->|Yes| C[Render Vue components]
    B -->|No| D[Render prose elements]
    C --> E[Output page]
    D --> E
```
````
::

- Switches the Mermaid theme with the site's color mode
- Loads `mermaid` and renders only once the diagram enters the viewport
- Sanitizes the output with DOMPurify and runs Mermaid with `securityLevel: 'strict'`
- Shows copy and fullscreen buttons in the top-right corner on hover

### Filename

As with regular code blocks, put a filename in square brackets to show it above the diagram:

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```mermaid [ai-chat.mmd]
sequenceDiagram
    participant U as Reader
    participant P as Docs page
    participant A as AI Chat
    participant M as MCP Server
    U->>P: Ask a question
    P->>A: Send message
    A->>M: Call docs tools
    M-->>A: Return matching pages
    A-->>U: Stream the answer
```

#code
````md
```mermaid [ai-chat.mmd]
sequenceDiagram
    ...
```
````
::

## Diagram types

### Class diagram

`classDiagram` shows types and inheritance:

```mermaid
classDiagram
    class Page {
        +String title
        +String description
        +String path
    }
    class DocsPage {
        +String category
        +Link[] links
    }
    class ReleasePage {
        +String tag
        +Date publishedAt
    }
    Page <|-- DocsPage
    Page <|-- ReleasePage
```

### State diagram

`stateDiagram-v2` shows state transitions:

```mermaid
stateDiagram-v2
    [*] --> Draft
    Draft --> Review: Open PR
    Review --> Draft: Changes requested
    Review --> Published: Merge
    Published --> [*]
```

### Pie chart

`pie` shows proportions:

```mermaid
pie title Example: page types
    "Guide" : 11
    "AI" : 5
    "Writing" : 6
    "Components" : 7
    "Reference" : 14
```

### Gantt chart

`gantt` shows schedules and milestones:

```mermaid
gantt
    title Example release plan
    dateFormat YYYY-MM-DD
    section Development
        Features    :a1, 2026-09-01, 21d
        Docs        :a2, after a1, 14d
    section Release
        Beta        :b1, after a2, 7d
        Stable      :milestone, after b1, 0d
```

### Entity relationship diagram

`erDiagram` shows entities and their relationships:

```mermaid
erDiagram
    COLLECTION ||--o{ PAGE : contains
    COLLECTION {
        string name
        string locale
    }
    PAGE ||--o{ SECTION : has
    PAGE {
        string path PK
        string title
        string category
    }
    SECTION {
        string id PK
        string heading
    }
```

::tip{to="https://mermaid.js.org/intro/"}
See the Mermaid docs for more diagram types and syntax.
::

## Styling

Override slot classes under `ui.prose.mermaid` in `app/app.config.ts`:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      mermaid: {
        slots: {
          root: 'my-8 border-primary/40',
          diagram: 'bg-default p-6'
        }
      }
    }
  }
})
```

## Images

### Remote images

::code-preview
![Nuxt social image](https://nuxt.com/new-social.jpg)

#code
```mdc
![Nuxt social image](https://nuxt.com/new-social.jpg)
```
::

### Local images

Put local images in the site's `public/` directory and reference them from `/`:

::code-preview
![Snowy mountains in a sea of clouds at sunset](/mountains.webp)

#code
```mdc
![Snowy mountains in a sea of clouds at sunset](/mountains.webp)
```
::

::note{to="https://image.nuxt.com/"}
Markdown images are rendered with `<NuxtImg>` instead of a plain `<img>`, so Nuxt Image optimizations apply.
::

The alt text in square brackets describes the image for screen readers and search engines. Avoid empty words such as "image" or "screenshot".

## Light and dark screenshots

When a UI screenshot looks very different in light and dark mode, provide both with `u-color-mode-image`; the page shows the one matching the current theme:

::code-preview
:u-color-mode-image{light="/assets/templates/movk-nuxt-light.png" dark="/assets/templates/movk-nuxt-dark.png" alt="Home page of the @movk/nuxt docs site" class="rounded-md border border-default"}

#code
```mdc
:u-color-mode-image{light="/assets/templates/movk-nuxt-light.png" dark="/assets/templates/movk-nuxt-dark.png" alt="Home page of the @movk/nuxt docs site" class="rounded-md border border-default"}
```
::

::tip
Keep both images the same size so the page does not shift when the theme changes.
::

## Video

`:video` renders a native `<video>` element with the usual HTML attributes:

::code-preview
:video{autoplay controls loop muted src="https://media.w3.org/2010/05/sintel/trailer.mp4"}

#code
```mdc
:video{autoplay controls loop muted src="https://media.w3.org/2010/05/sintel/trailer.mp4"}
```
::

Browsers only autoplay muted videos, so add `muted` together with `autoplay`.

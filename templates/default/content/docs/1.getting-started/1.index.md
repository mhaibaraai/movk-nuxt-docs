## 目录结构

| 路径 | 作用 |
| --- | --- |
| `content/index.md` | 首页，由 `LandingCover`、`LandingSection` 等落地页组件组成 |
| `content/docs/` | 文档页面，目录与文件名的数字前缀决定侧栏顺序 |
| `app/app.config.ts` | 页头导航、侧栏分类、页脚等运行时配置 |
| `nuxt.config.ts` | 功能开关、MCP、llms.txt 等模块配置 |
| `.env.example` | 可用的环境变量，复制为 `.env` 后填写 |

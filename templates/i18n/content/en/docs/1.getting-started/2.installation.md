## Install

::code-group
```bash [pnpm]
pnpm add my-package
```

```bash [npm]
npm install my-package
```

```bash [yarn]
yarn add my-package
```
::

## Usage

```ts [main.ts]
import { hello } from 'my-package'

hello()
```

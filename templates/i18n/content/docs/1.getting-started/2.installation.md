## 安装依赖

::code-group
```bash [pnpm]
pnpm add my-package
```

```bash [npm]
npm install my-package
```

```bash [yarn]
yarn add my-package
```
::

## 基本用法

```ts [main.ts]
import { hello } from 'my-package'

hello()
```
